TAYLOR SERIES EXPLORER
By Group 3 of BTIS1 | Aguilar, Bernal, Cabrera, Obille, Rivera


WHAT DOES IT DO?
The app approximates e^x, ln(x), sin(x), cos(x) and tan(x) by adding up a finite number of terms of each function's series. The user picks the function, an x value and the number of terms. 


WHAT ARE THE REQUIREMENTS TO RUN THIS APPLICATION?
Python must be 3.10 or newer. 
Packages include matplotlib (installs numpy and others automatically)


HOW TO RUN THE APP?
From the project folder, with the virtual environment active: python gui.py


HOW TO USE THE APP?
1. Choose a function from the drop-down. The hint line shows the allowed x range and term limit.
2. Type an x value and the number of terms.
3. Click Calculate.
4. Read the Results, Series, Term table and graph.
5. Tick or untick Show partial sums on graph to show or hide the faint 1-term to n-term curves.
If the input is invalid, a red message appears at the bottom and the app keeps running.
